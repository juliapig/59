# Julia Portfolio Website

A responsive personal portfolio website for a designer.

## Files

- `index.html` - page structure and content
- `styles.css` - visual design, layout, and animations
- `script.js` - scroll reveal animation

## Run Locally

Open `index.html` directly in your browser,
or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Customize Quickly

- Update text content in `index.html`
- Update colors in `styles.css` under `:root`
- Replace links in the contact section in `index.html`
- Change the email address in header/contact buttons
